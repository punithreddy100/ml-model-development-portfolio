Machine Learning Algorithm Map

This artifact provides a simple map of machine learning models and learning approaches. It explains how supervised learning, unsupervised learning, generative AI, and model selection relate to real-world use cases in data science, software development, and business decision-making.

Overview

  • Supervised learning uses labeled data to predict outcomes.
  • Unsupervised learning finds patterns and structure in unlabeled data.
  • Generative AI creates new content such as text, images, or synthetic media.
  • Model selection depends on data type, problem type, resources, and performance goals.
