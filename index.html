Introduction

Machine learning is an important part of modern artificial intelligence because it enables systems to identify patterns, learn from data, and support predictions or decisions.

Objective

Purpose of the artifact

The objective is to demonstrate an understanding of how machine learning algorithms differ in learning approaches, technical functions, and application areas.

Value

Why this matters

This artifact connects algorithm functions to practical business and technology problems, making technical concepts easier to understand for students and professional audiences.

Learning Types

Machine learning methods are organized by how they learn from data and what they are designed to produce.

Supervised Learning

Uses labeled examples to learn mappings between input features and target values.

Unsupervised Learning

Discovers structure and hidden patterns in data without predefined labels.

Generative Models

Learn patterns in data to create new content such as text, images, or synthetic output.

Hybrid / Multi-use

Some methods can serve classification, prediction, and generation depending on the task.

Algorithm Families

The framework includes predictive, clustering, dimensionality reduction, and generative methods.

Regression

Linear Regression

Predicts numerical outcomes using relationships between input variables and the target value.

Decision-Based

Decision Trees

Creates rule-based decisions for interpretable classification and regression tasks.

Ensemble

Random Forests

Combines many trees to improve stability and prediction accuracy on structured data.

Boosting

Gradient Boosting

Builds models sequentially to reduce errors and improve prediction quality.

Margin-Based

Support Vector Machines

Finds boundaries that best separate data classes in high-dimensional feature spaces.

Vision

Convolutional Neural Networks

Detects patterns in images and visual data through convolutional operations.

Clustering

K-Means

Groups similar observations based on distance to cluster centroids.

Reduction

Principal Component Analysis

Reduces dimensionality while retaining the most important information from the data.

NLP

Transformers

Uses attention to model context in text and supports language understanding and generation.

Generative

Diffusion Models

Learn to reverse noise to generate realistic content such as images or media.

Generative

GANs

Uses competing generator and discriminator networks to learn realistic data distributions.

Selection

Model Choice

Depends on data, expected output, computational constraints, and evaluation criteria.
